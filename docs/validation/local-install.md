# 個人利用向け配置とアイコンの検証

確認日：2026-10-21。macOS 26.6.2 / Xcode 27.1 / macOS SDK 27.0。配布用の公証・他環境へのインストールは未確認です。

## 利用方法

```sh
./scripts/install-local.sh
open "$HOME/Applications/InMyFace.app"
```

配置スクリプトはReleaseビルドを作成し、ビルド元とコピー後の署名を検証してから`~/Applications/InMyFace.app`を置き換えます。既存のローカル署名設定を使います。アプリが起動中の場合は停止して終了操作を案内します。配置先がシンボリックリンク、または別Bundle IDのアプリの場合も置換しません。

コピーは配置先の一時ディレクトリで行い、旧アプリの移動後に置換が失敗した場合は終了時の処理で旧アプリを戻します。設定やDismiss履歴の保存先には触れません。強制終了・電源断・ストレージ障害を含む更新トランザクションの保証はありません。配置処理は1つずつ実行してください。

## ログイン時起動の実機確認

継続して利用する配置先のアプリから登録します。最新版を配置し、[ログイン時起動の確認項目](login-item.md#実機確認に残る項目)に従って、ON・OS承認・次回ログイン・OFFを確認します。OS側の許可を自動で変更する処理はありません。移動・削除前には登録を解除します。

整形チェック、`git diff --check`、ローカルリンク49件の確認も正常です。
